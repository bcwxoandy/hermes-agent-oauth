# hermes-agent-oauth

Personal, single-user OAuth client used by a self-hosted local assistant
("Hermes Agent") running on its owner's own computer.

## Purpose
Let the owner search and read the owner's own Gmail mailbox, read Google
Calendar, and read (read-only) Google Contacts from that local assistant.

## Use
- Authorizes only the owner's personal Google account.
- No public sign-in, no third-party users, no multi-tenant service.
- OAuth tokens are stored locally on the owner's machine only.
- No data is sold, shared, or transferred to any third party.
