# Privacy Policy - hermes-agent-oauth

Last updated: 2026-10-08

## What this application is
A personal, non-commercial, single-user tool. It runs locally on its owner's own
computer and is not offered as a service to anyone else.

## What data it accesses
Google account data that the account owner authorizes through Google OAuth 2.0:

- Gmail: messages, threads, labels and metadata
- Google Calendar: the owner's calendars and events
- Google Contacts: read-only

## How the data is used
Only at the owner's explicit request, on the owner's own computer: to search and
read mail, to summarise it, to keep calendar dates in view, and - only when the
owner asks - to prepare or send a message from the owner's own account.

## Where the data is stored
Locally on the owner's own computer. OAuth credentials are stored in a local file
whose permissions are restricted to the owner. Data is not uploaded to any
third-party server, cloud storage, or analytics service.

## Sharing
No data is sold, rented, licensed, or shared with any third party. No data is
used for advertising, profiling, or for training machine-learning models.

## Retention and deletion
Data is retained locally only for as long as the owner keeps it; the owner may
delete it at any time. Access can be revoked at any time at
https://myaccount.google.com/permissions, after which the stored tokens are
invalid and no further access is possible.

## Google API Limited Use
This application's use of information received from Google APIs adheres to the
Google API Services User Data Policy, including the Limited Use requirements.
